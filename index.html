Projects & Skills

Four things I have learned so far in ICT251, and where this website uses them.

Semantic HTML5

I structure pages with header, nav, main, section and footer, add descriptive alt text, and connect every form label to its field so the page works for everyone.

Responsive CSS

I use the box model, colour variables, flexible images and a media query so this site stays readable on a phone and on a computer.

JavaScript and the DOM

I respond to clicks and form submissions to update the page: the photo viewer, the theme switch, the phone menu and the contact form preview.

Safe handling of user input

As a Cyber Security student, I validate form input and display it with textContent, so text typed by a visitor is never run as HTML code.
